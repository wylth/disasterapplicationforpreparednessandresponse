# Disaster Preparedness and Response App

A mobile application designed to help users prepare for and respond to disaster situations.

## Overview

The application provides real-time disaster information, emergency resources, and interactive preparedness tools. It integrates the GDACS API to retrieve real time disaster alerts and uses AsyncStorage for offline data persistence.

## Features

- Real time disaster alerts and filtering
- Emergency shelter and hotline information
- Interactive preparedness checklists
- Multiple choice preparedness quizzes
- Badge-based reward system
- Offline data persistence
- User status sharing

## Technologies

- React Native
- Expo
- JavaScript
- REST APIs
- AsyncStorage


## Getting Started

### Installation

    npm install

### Run the application

    npx expo start

The application can then be opened using an available Expo development environment.

## Project Structure

- `app/` — Application screens and routes
- `components/` — Reusable UI components
- `hooks/` — React hooks
- `assets/` — Application assets
- `tests/` — Test files
